One decimal digit per nibble

BCD is not ordinary binary. Each decimal digit is stored independently in four bits, so only nibbles 0000–1001 are legal.

Leading zeros are preserved: 0059 uses three BCD groups.

Why the lengths differ

Decimal 59 becomes 0101 1001 in BCD (8 bits) but 111011 in binary (6 bits). BCD trades compactness for easy digit display and decimal arithmetic.

Reflected Gray code

One bit changes between neighbors

Gray code is an unsigned ordering of fixed-width patterns. Consecutive codes differ in exactly one bit, which helps avoid transient multi-bit changes.

Not a numeric base

Gray code represents positions, not ordinary place-value digits. It is decoded back to binary before arithmetic.

Single-bit parity

Detect a change, not its location

Generate an even or odd parity bit, then flip one data bit to see the receiver's check fail. Parity never corrects the error.

Limit of the check

Single-bit parity detects an odd number of flips. Any even number of flips leaves parity unchanged, and a detected error cannot be located without more redundant bits.
